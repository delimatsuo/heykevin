# iOS 1.3.5 (50) — App Store submission

Submitted for App Store review 2026-10-15 (WAITING_FOR_REVIEW). Release type **MANUAL**, **phased release** attached. Live production remains **1.3.4**. No backend change.

## Rollback plan
- Before release: cancel the review submission in App Store Connect; 1.3.4 stays live. Nothing reaches users without a manual Release click.
- Release only after Deli confirms Build 50 on device. Start phased release (7 days: 1/2/5/10/20/50/100%).
- If problems appear mid-rollout: **Pause** phased release (stops new auto-updates; users still on 1.3.4 are unaffected), then ship a hotfix build with expedited review.
- Apple does not allow reverting users to 1.3.4. Already-updated users get the hotfix. The backend is untouched and compatible with 1.3.4 and 1.3.5, so server rollback is not involved.
- Known deliberate changes: Spam filter chip hidden; Mark All Read always visible; unified light design (forced light mode).
